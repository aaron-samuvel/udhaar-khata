# உதார் கட்டா (Udhaar Khata)

கிரணா கடைகளுக்கான டிஜிட்டல் கடன் பதிவேடு. வாடிக்கையாளர்களைச் சேர்க்கவும், கடன் (உதார்) மற்றும் பணம் செலுத்தியதை பதிவு செய்யவும், நிலுவைத் தொகையைக் கண்காணிக்கவும் - அனைத்தும் உங்கள் உலாவிக்குள்ளேயே.

**நேரடி இணைப்பு:** https://aaron-samuvel.github.io/udhaar-khata/

## முக்கிய அம்சங்கள்
- உள்நுழைவு இல்லை, சேவையகம் இல்லை - தரவு உங்கள் சாதனத்தில் மட்டும்
- ஆஃப்லைன் PWA - செயலியாக நிறுவி பயன்படுத்தலாம்
- தொகைகள் முழு பைசா எண்ணாக (integer) சேமிப்பு - வட்ட மாற்றப் பிழை இல்லை
- தவறுகளை திருத்த reversal entries - பதிவுகள் எப்போதும் நீக்கப்படுவதில்லை
- Backup / Restore - புதிய சாதனத்திற்கு தரவை எளிதாக மாற்றலாம்
