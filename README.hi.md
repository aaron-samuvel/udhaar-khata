# उधार खाता (Udhaar Khata)

किराना दुकानों के लिए डिजिटल उधार खाता। ग्राहक जोड़ें, उधार और जमा दर्ज करें, बकाया पर नज़र रखें - सब कुछ आपके ब्राउज़र में ही।

**लाइव ऐप:** https://aaron-samuvel.github.io/udhaar-khata/

## खास बातें
- बिना लॉगिन, बिना सर्वर - डेटा केवल आपके डिवाइस पर
- ऑफ़लाइन PWA - इंस्टॉल करके ऐप की तरह चलाएँ
- पैसा पूर्ण पैसे (integer paise) में - गोलाई की गलती नहीं
- गलती के लिए reversal entry - पुरानी entry कभी delete नहीं होती
- Backup / Restore - नए फ़ोन पर डेटा ले जाना आसान
