# Support

## Where to get help
1. **Documentation** - check the [`docs/`](docs/) folder and the [README](README.md).
2. **Discussions** - ask questions in [GitHub Discussions](https://github.com/aaron-samuvel/udhaar-khata/discussions).
3. **Issues** - if you found a bug, open an issue using the bug report template.

## Before asking
- Try the [FAQ](docs/FAQ.md) and the [Troubleshooting guide](docs/TROUBLESHOOTING.md).
- Check whether your data is intact via the backup/restore screen before filing a data-loss report.

## What NOT to use issues for
- Questions -> use Discussions
- Security vulnerabilities -> see [SECURITY.md](SECURITY.md)
