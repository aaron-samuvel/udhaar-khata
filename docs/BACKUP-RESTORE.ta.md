# காப்பு மற்றும் மீட்டமைப்பு (தமிழ்)

உங்கள் முழு கணக்கும் உங்கள் உலாவியில் மட்டுமே இருக்கும் - எனவே காப்பு உங்கள் பொறுப்பு.

## காப்பு எடுப்பது
1. செயலியைத் திறக்கவும் -> **Backup / Restore**.
2. **Export backup** அழுத்தவும் - ஒரு JSON கோப்பு பதிவிறக்கமாகும்.
3. அதை Google Drive, மின்னஞ்சல் அல்லது கணினியில் பாதுகாக்கவும்.

## மீட்டமைப்பது
1. புதிய சாதனத்தில் செயலியைத் திறக்கவும்.
2. **Backup / Restore -> Import backup** -> கோப்பைத் தேர்ந்தெடுக்கவும்.

## விதிகள்
- தினமும் கடை மூடும்போது காப்பு எடுங்கள் - பணம் எண்ணுவது போன்ற பழக்கமாக்கிக் கொள்ளுங்கள்.
- காப்பு கோப்பில் வாடிக்கையாளர் பெயர்களும் தொகைகளும் உள்ளன - குழுக்களில் பகிர வேண்டாம்.
