# बैकअप और रिस्टोर (हिंदी)

आपका पूरा खाता सिर्फ़ आपके ब्राउज़र में रहता है - इसलिए बैकअप आपकी ज़िम्मेदारी है।

## बैकअप लेना
1. ऐप खोलें -> **Backup / Restore**.
2. **Export backup** दबाएँ - एक JSON फ़ाइल डाउनलोड होगी।
3. उसे Google Drive, ईमेल, या कंप्यूटर पर सुरक्षित रखें।

## रिस्टोर करना
1. नए डिवाइस पर ऐप खोलें।
2. **Backup / Restore -> Import backup** -> फ़ाइल चुनें।

## नियम
- रोज़ बंद करते समय बैकअप लें - कैश गिनने की तरह आदत बना लें।
- बैकअप फ़ाइल में ग्राहक के नाम और रकम होती है - किसी ग्रुप में शेयर न करें।
