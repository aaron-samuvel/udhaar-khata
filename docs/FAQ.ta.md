# அடிக்கடி கேட்கப்படும் கேள்விகள் (FAQ)

**என் தரவு எங்கே சேமிக்கப்படுகிறது?**
உங்கள் உலாவியின் `localStorage`-ல் - உங்கள் சாதனத்தில் மட்டுமே. சேவையகம் இல்லை.

**செயலி இலவசமா?**
ஆம் - இது திறந்த மூல (open source) மென்பொருள்.

**புதிய போனுக்கு தரவை எப்படி மாற்றுவது?**
பழைய போனில் Backup / Restore மூலம் காப்பு கோப்பை எடுங்கள், புதிய போனில் Import செய்யுங்கள் - [BACKUP-RESTORE.ta.md](BACKUP-RESTORE.ta.md) பார்க்கவும்.

**உலாவி தரவை அழித்தால் என்ன ஆகும்?**
`localStorage`-ல் உள்ளது அனைத்தும் அழியும். தொடர்ந்து காப்பு எடுங்கள்.

**கணக்கு திறக்க வேண்டுமா?**
இல்லை - உள்நுழைவு இல்லை. பதிவேடு முற்றிலும் உங்களுடையது.

**ஆஃப்லைனில் வேலை செய்யுமா?**
ஆம் - இது ஒரு PWA. ஒரு முறை திறந்த பிறகு நெட்வொர்க் இல்லாமலும் இயங்கும்.
