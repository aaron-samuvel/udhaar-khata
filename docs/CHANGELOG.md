# Changelog

Notable changes to Udhaar Khata. Format loosely follows Keep a Changelog.

## [1.0.0] - initial public release
### Added
- Static GitHub Pages deployment with PWA offline support
- Customer ledger: udhaar entries, payments, running balance
- Money stored as integer paise with en-IN formatting
- Reversal-based corrections (no destructive deletes)
- Backup / restore via JSON export
- Contributor docs, community health files, and maintenance workflows
