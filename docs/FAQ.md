# FAQ

**Where is my data stored?**
In your browser's `localStorage` (static deploy) or the local SQLite file (self-hosted build). Nothing leaves your device.

**Is the app free?**
Yes - it is open source under the repository license.

**How do I move data to a new phone?**
Use the backup/restore screen: export a backup file on the old device, open the app on the new device, restore. See [BACKUP-RESTORE.md](BACKUP-RESTORE.md).

**What happens if I clear browser data?**
`localStorage` is wiped with it. Keep regular backups.

**Do I need an account?**
No sign-up, no login. The ledger is yours alone.

**Does it work offline?**
Yes - the app is a PWA. Once loaded, it works without a network.
