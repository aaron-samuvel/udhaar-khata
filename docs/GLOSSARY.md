# Glossary

Terms you will meet in the codebase and UI:

| Term | Meaning |
|------|---------|
| **Udhaar** | Credit - goods or cash given now, payment promised later |
| **Khata** | Ledger / account book |
| **Baki / Bakaya** | Balance due, outstanding amount |
| **Jama** | Payment received, credit to the account |
| **Reversal** | An opposite entry that cancels a mistake without deleting it |
| **Paise** | 1/100 of a rupee; all stored amounts use integer paise |

Using these terms consistently in code and docs keeps the domain language intact.
