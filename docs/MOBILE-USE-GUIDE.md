# Mobile use guide

The app is designed phone-first - most shopkeepers run it on a single Android phone.

## Setup
1. Open the app in Chrome, install as a PWA (see [PWA-OFFLINE.md](PWA-OFFLINE.md)).
2. Every screen works portrait - hold it however suits the counter.

## Daily rhythm
- Morning: open app, glance at top dues.
- During the day: log udhaar immediately - memory lies by evening.
- Payment received? Log it in front of the customer; it builds trust.
- Night: export a backup.

## Care
- Only this browser holds the data - do not "Clear site data" for this origin.
- Clearing browsing history may wipe site data too; use browser settings carefully.
