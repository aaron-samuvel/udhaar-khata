# अक्सर पूछे जाने वाले सवाल (FAQ)

**मेरा डेटा कहाँ सेव होता है?**
आपके ब्राउज़र के `localStorage` में - केवल आपके डिवाइस पर। कोई सर्वर नहीं।

**क्या ऐप मुफ़्त है?**
हाँ, यह ओपन सोर्स है।

**फ़ोन बदलने पर डेटा कैसे ले जाऊँ?**
पुराने फ़ोन पर Backup / Restore से बैकअप फ़ाइल निकालें, नए फ़ोन पर Import करें - [BACKUP-RESTORE.hi.md](BACKUP-RESTORE.hi.md) देखें।

**ब्राउज़र डेटा साफ़ करने पर क्या होगा?**
`localStorage` भी मिट जाएगा। नियमित बैकअप लें।

**अकाउंट बनाना ज़रूरी है?**
नहीं - ना लॉगिन, ना साइनअप। खाता पूरी तरह आपका है।

**ऑफ़लाइन चलता है?**
हाँ - यह PWA है। एक बार खोलने के बाद बिना नेट भी चलता है।
