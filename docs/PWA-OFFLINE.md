# PWA & offline use

Udhaar Khata is an installable Progressive Web App.

## Install on Android (Chrome)
1. Open https://aaron-samuvel.github.io/udhaar-khata/
2. Menu (three dots) -> **Add to Home screen** / **Install app**.
3. Launch like a normal app - full screen, no browser bars.

## Install on iOS (Safari)
1. Open the site in Safari.
2. Share -> **Add to Home Screen**.

## Offline behavior
- After the first load, the app shell and your data are available offline.
- Entries created offline are saved locally and remain when you reconnect.
- Storage is per-browser: incognito windows do not persist data.

## Caveats
- Clearing site data removes the ledger - keep backups ([BACKUP-RESTORE.md](BACKUP-RESTORE.md)).
