# Roadmap

Udhaar Khata is a digital credit ledger for Indian kirana stores. Priorities below are indicative and community-driven - open a Discussion to propose changes.

## Near term
- [ ] Multi-language UI (Hindi, Tamil beyond READMEs)
- [ ] CSV export polish and round-trip import validation
- [ ] Reminder copy templates (WhatsApp / SMS) for pending udhaar

## Mid term
- [ ] Optional cloud sync (user-supplied storage)
- [ ] Multi-shop profiles on one device
- [ ] PDF statement generation per customer

## Done
- [x] Static GitHub Pages deployment with offline PWA
- [x] Integer-paise money handling with reversal-based corrections
